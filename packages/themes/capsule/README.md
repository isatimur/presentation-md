# capsule

**Memphis-meets-editorial pills on warm bone.**

```bash
npm i @presentation-md/theme-capsule
```

Use: `"meta": { "theme": "capsule" }` · Surface: `capsule-pills`.

Surface craft: plump rounded frame, hard ink offset shadow, pastel radial blots, and hero-gated coral pill + lime circles (HTML). PPTX mirrors frame/offset-shadow strips/blots and gates loud pills to title/closing.
