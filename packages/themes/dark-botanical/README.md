# dark-botanical

**Elegant dark with warm botanical accents.**

```bash
npm i @presentation-md/theme-dark-botanical
```

Use: `"meta": { "theme": "dark-botanical" }` · Surface: `dark-botanical-bloom`.

Faithful to frontend-slides `STYLE_PRESETS Dark Botanical`.

Surface craft: dual bloom washes, soft shadow, left accent rail (HTML). PPTX mirrors denser bloom ovals + soft shadow stub + left rail; cards get square hairline strokes.
