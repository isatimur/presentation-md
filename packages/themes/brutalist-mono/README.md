# brutalist-mono

**Raw brutalist** presentation theme for presentation-md.
Concrete off-white background, near-black monospace type (IBM Plex Mono), a single hazard-orange
accent, thick near-black hairlines, zero border radius. No decoration, all structure.

## Install

```bash
npm i @presentation-md/theme-brutalist-mono
```

## Usage

```json
{
  "meta": { "theme": "brutalist-mono" },
  "slides": []
}
```
