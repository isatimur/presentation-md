# retro-windows

**Windows 95 chrome windows with navy title bars and CRT scanlines.**

```bash
npm i @presentation-md/theme-retro-windows
```

Use: `"meta": { "theme": "retro-windows" }` · Surface: `retro-windows-chrome`.

Faithful to frontend-slides `bold-template-pack retro-windows`.

Surface craft: Win95 beveled chrome (white/black outer bevel + inset hilite/shade), navy title bar, window buttons, CRT scanlines (HTML). PPTX mirrors the bevel/inset strips + chrome.
