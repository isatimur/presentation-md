# raw-grid

**Neo-brutalist thick borders with blush/sage accents and hard shadows.**

```bash
npm i @presentation-md/theme-raw-grid
```

Use: `"meta": { "theme": "raw-grid" }` · Surface: `raw-grid-brutal`.

Faithful to frontend-slides `bold-template-pack raw-grid`.

Surface craft: blush/sage bands + cross rules + ink frame + offset shadow on every slide (HTML). PPTX mirrors bands/rules/frame/shadow + square hard-border cards.
