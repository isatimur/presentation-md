# emerald-editorial

**Fashion-masthead emerald with double-rule ornaments.**

```bash
npm i @presentation-md/theme-emerald-editorial
```

Use: `"meta": { "theme": "emerald-editorial" }` · Surface: `emerald-editorial-masthead`.

Faithful to frontend-slides `bold-template-pack emerald-editorial`.

Surface craft: double masthead rules plus quiet paper grain (HTML). PPTX approximates rules/frame — grain is HTML-only.
