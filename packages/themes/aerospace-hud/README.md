# aerospace-hud

**Aerospace HUD — deep navy, cyan instruments, warning orange, blueprint grid.**

Install (npm):

```bash
npm i @presentation-md/theme-aerospace-hud
```

Use in deck JSON: `"meta": { "theme": "aerospace-hud" }`

Surface profile: `hud-grid`.

Surface craft: instrument grid + cyan rim + reticle + orange telemetry stub (HTML). PPTX densifies grid/reticle crosshair/telemetry + square accent card hairlines.
