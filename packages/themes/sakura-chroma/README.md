# sakura-chroma

**Cassette-package cream with chroma stamps and condensed display.**

```bash
npm i @presentation-md/theme-sakura-chroma
```

Use: `"meta": { "theme": "sakura-chroma" }` · Surface: `sakura-chroma-cassette`.

Faithful to frontend-slides `bold-template-pack sakura-chroma`.

Surface craft: hard frame + accent-tinted offset shadow on every slide; chroma strip + stamp orbs on heroes (HTML). PPTX mirrors frame/shadow + hero chroma/stamps and hard-border cards.
