# editorial-serif

**Magazine editorial** presentation theme for presentation-md.
Warm cream paper background, near-black ink serif text (Playfair Display / Source Serif 4),
a single masthead-crimson accent with a brass secondary, thin hairline rules, square corners.

## Install

```bash
npm i @presentation-md/theme-editorial-serif
```

## Usage

```json
{
  "meta": { "theme": "editorial-serif" },
  "slides": []
}
```
