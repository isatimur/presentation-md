## 1.0.0

### Major Changes

- e9b8afd: Rename the pack from presentation-skill-pack to presentation-md to match the GitHub repo.

  Breaking: npm scope is now `@presentation-md/*`, CLIs are `presentation-md-*` /
  `create-presentation-md-theme`, PyPI packages are `presentation-md-*`, and the site
  hostname is `presentation-md.vercel.app`.

### Minor Changes

- e9b8afd: Add three new themes: editorial-serif, brutalist-mono, and pastel-dreamy.

  - `editorial-serif` — warm cream paper, ink-black serif type, crimson masthead accent
  - `brutalist-mono` — concrete off-white, IBM Plex Mono, hazard-orange accent, zero radius
  - `pastel-dreamy` — lavender-blush canvas, deep plum text, blush + periwinkle accents
