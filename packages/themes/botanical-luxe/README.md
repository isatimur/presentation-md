# botanical-luxe

**Botanical luxe — deep forest green, gold leaf, serif elegance for impact reports.**

```bash
npm i @presentation-md/theme-botanical-luxe
```

Use: `"meta": { "theme": "botanical-luxe" }` · Surface: `botanical-leaf`.

Surface craft: gold hairline frame, soft shadow, leaf ring, accent2 wash (HTML). PPTX mirrors always-on gold frame + soft shadow stub + leaf ring + wash; cards get square hairline strokes.
