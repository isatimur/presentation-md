# block-frame

**Neobrutalist candy blocks with hard black frames.**

```bash
npm i @presentation-md/theme-block-frame
```

Use: `"meta": { "theme": "block-frame" }` · Surface: `block-frame-brutal`.

Faithful to frontend-slides `bold-template-pack block-frame`.

Surface craft: hard black frame + ink offset shadow on every slide; pastel offset blocks on heroes (HTML). PPTX mirrors frame/shadow + hero blocks and square hard-border cards.
