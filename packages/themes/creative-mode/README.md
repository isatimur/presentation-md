# creative-mode

**Neo-brutalist zine — cream, 4px ink borders, loud color blocks.**

```bash
npm i @presentation-md/theme-creative-mode
```

Use: `"meta": { "theme": "creative-mode" }` · Surface: `creative-mode-blocks`.

Faithful to frontend-slides / beautiful-html-templates `creative-mode`.

Surface craft: hard ink frame + offset shadow on every slide; stacked accent blocks on heroes (HTML). PPTX mirrors frame/shadow + hero blocks and square hard-border cards.
