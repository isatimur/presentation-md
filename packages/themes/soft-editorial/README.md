# soft-editorial

**A warm magazine spread — Cormorant on cream with soft pastel candy cards.**

```bash
npm i @presentation-md/theme-soft-editorial
```

Use: `"meta": { "theme": "soft-editorial" }` · Surface: `soft-editorial-paper`.

Faithful to frontend-slides / beautiful-html-templates `soft-editorial`.

Surface craft: soft blush orb on heroes, pastel candy cards, and a quiet paper
fiber grain on every slide (HTML). PPTX approximates sage wash + hero-gated blush/
lemon/lilac candy + plump inset frame + card radius — grain is HTML-only.
