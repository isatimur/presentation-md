# notebook-tabs

**Cream paper notebook with colorful section tabs on the edge.**

```bash
npm i @presentation-md/theme-notebook-tabs
```

Use: `"meta": { "theme": "notebook-tabs" }` · Surface: `notebook-tabs-page`.

Faithful to frontend-slides / beautiful-html-templates `notebook-tabs`.

Surface craft: pastel side tabs, binder holes, and quiet cream paper grain (HTML). PPTX approximates tabs/holes — grain is HTML-only.
