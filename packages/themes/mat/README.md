# mat

**Dark sage with wood glow and burnt-orange mid-century accent.**

```bash
npm i @presentation-md/theme-mat
```

Use: `"meta": { "theme": "mat" }` · Surface: `mat-woodglow`.

Surface craft: woodglow radials, cream inset rim, burnt-orange hairlines (heroes also get a mid-century accent block). PPTX mirrors denser woodglow + cream rim + hairlines + square dark card strokes.

Faithful to frontend-slides `bold-template-pack mat`.
