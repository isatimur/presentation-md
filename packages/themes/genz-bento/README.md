# genz-bento

**Gen-Z hard-shadow bento — hot coral, lime stickers, chunky ink borders.**

Install (npm):

```bash
npm i @presentation-md/theme-genz-bento
```

Use in deck JSON: `"meta": { "theme": "genz-bento" }`

Surface profile: `hard-bento`.

Surface craft: hard ink frame + offset shadow + accent2 corner blot on every slide; plump hard-border cards. PPTX mirrors frame/shadow/blot + card strokes.
