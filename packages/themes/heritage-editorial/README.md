# heritage-editorial

**Heritage editorial — warm parchment, terracotta blush, Playfair + Cormorant serif.**

```bash
npm i @presentation-md/theme-heritage-editorial
```

Use: `"meta": { "theme": "heritage-editorial" }` · Surface: `heritage-wash`.

Surface craft: parchment wash, terracotta hairlines, and a quiet paper fiber grain (HTML). PPTX approximates wash + hairlines — grain is HTML-only.
