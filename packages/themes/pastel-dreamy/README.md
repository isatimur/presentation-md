# pastel-dreamy

**Soft pastel** presentation theme for presentation-md.
Lavender-blush background, deep plum text (Quicksand / Mulish) for real readability against the
pastel base, a blush-pink + periwinkle accent pair, generously rounded corners.

## Install

```bash
npm i @presentation-md/theme-pastel-dreamy
```

## Usage

```json
{
  "meta": { "theme": "pastel-dreamy" },
  "slides": []
}
```
