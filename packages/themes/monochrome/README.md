# monochrome

**Ivory ledger paper with ultra-light Jost and no chromatic accents.**

```bash
npm i @presentation-md/theme-monochrome
```

Use: `"meta": { "theme": "monochrome" }` · Surface: `monochrome-ledger`.

Faithful to frontend-slides `bold-template-pack monochrome`.

Surface craft: ledger hairlines plus quiet ivory paper grain (HTML). PPTX approximates hairlines — grain is HTML-only.
