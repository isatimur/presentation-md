# paper-ink

**Literary cream with crimson accent.**

```bash
npm i @presentation-md/theme-paper-ink
```

Use: `"meta": { "theme": "paper-ink" }` · Surface: `paper-ink-literary`.

Faithful to frontend-slides `STYLE_PRESETS Paper & Ink`.

Surface craft: crimson rules plus a quiet literary paper grain (HTML). PPTX approximates the frame/rules and hero-gates the corner blot + drop-cap stub; cards get a crimson left accent rule (literary rail). Grain stays HTML-only. Literary left-rule peers: `editorial-serif`, `vintage-editorial`.
