# create-theme/src

## Overview

The `create-presentation-md-theme` CLI and its library exports. It scaffolds a theme package from Mustache templates. Theme values come from interactive prompts, a local CSS file (`--from-css`), a live brand URL (`--from-url`), or a PowerPoint template (`--from-pptx`). URL extraction first parses static CSS. If that finds nothing, it falls back to computed styles in headless Chromium. Template extraction reads the colour scheme and fonts with `extractTemplateBrand` from `@presentation-md/export/import`.

## Interface

- CLI `create-presentation-md-theme [name] [--output-dir <path>] [--from-url <url>] [--from-css <path>] [--from-pptx <file>] [--allow-office-default]` [index.ts:buildProgram].
- Scaffolding [index.ts]: `scaffoldTheme(view, outputDir)`, `buildThemeManifestJson(view)`, `renderTemplate(templateDir, filename, view)`, `getTemplateDir()`, `ThemeView` (with `headingStack`, `bodyStack`, `googleFonts`).
- Name helpers: `validateThemeName`, `toUnderscored` [index.ts]; `pickExtendsFromBg` [pick-extends.ts, re-exported from index.ts]; `deriveNameFromUrl`, `deriveNameFromPath` [name-from-url.ts].
- Brand extraction: `extractBrand({ url | cssPath | pptxPath })`, `BrandExtractionInput`, `BrandExtractionResult` (with `extends`, `fontPlan`, `warnings`, `logo`, `scheme`), `BrandSource`, `TemplateSchemeReport`, `MAX_LOCAL_CSS_BYTES` [extract-brand.ts]; `buildThemeViewFromBrand(name, extraction)` [theme-view.ts].
- Template roles: `templateToCandidates(brand)` and its thresholds [template-candidates.ts].
- Fonts: `buildFontPlan(heading, body, base)`, `classifyFont`, `sanitizeFamily`, `FontRow`, `FontPlan`, `FontStatus` [fonts.ts]; `GOOGLE_FONT_FAMILIES` [google-font-families.ts, generated by `pnpm fonts:update` from `tools/update-google-fonts.ts`].
- Office default guard: `assertNotOfficeDefault(result, allow)` [office-default.ts].
- Static fetch (internal module): `fetchStylesheetsFromUrl`, `fetchText`, `resolvePublicUrl`, `assertPublicHostname`, `isPublicNetworkAddress` [fetch-css.ts].
- Chromium fallback (internal module): `extractComputedStyles`, `ensurePlaywrightInstalled`, `guardRoute`, `isPublicHttpUrl`, `ComputedStyleResult` [playwright-fallback.ts].
- `template/` (not a contract directory): `theme.json.mustache`, `package.json.mustache`, `pyproject.toml.mustache`, `README.md.mustache`, consumed by `scaffoldTheme` [index.ts:THEME_TEMPLATE_FILES].

## Invariants

- Theme names match `/^[a-z][a-z0-9-]*$/`; anything else throws [index.ts:validateThemeName, name-from-url.ts:deriveNameFromUrl].
- `--from-url`, `--from-css` and `--from-pptx` are mutually exclusive, in the CLI and in `extractBrand` [index.ts:buildProgram, extract-brand.ts:extractBrand].
- A name is required, except with `--from-url` (from the hostname) and `--from-pptx` (from the file name) [index.ts:buildProgram, name-from-url.ts:deriveNameFromPath].
- `--from-pptx` takes only `.pptx` or `.potx`. The CLI always writes, so it always calls `assertNotOfficeDefault`; an Office default exits 1 unless `--allow-office-default` [index.ts:buildProgram, office-default.ts].
- `extends` is `"claude"` when bg relative luminance >= 0.45, else `"default-tech"`. Unparseable bg gives `"default-tech"` [pick-extends.ts:pickExtendsFromBg]. `extractBrand` computes it once, from the final palette; `buildThemeViewFromBrand` reads it.
- Template role choice: `bg`/`text`/`bg2` resolve through the master's `clrMap`; `bg2` is kept when its contrast with `bg` is 1.03–1.6; an accent is not neutral (HSL saturation >= 12) and has contrast >= 1.5 with `bg`; `accent2` also needs contrast >= 1.2 with `accent` [template-candidates.ts:templateToCandidates].
- Fonts: family names are sanitized to letters, digits, spaces, `.`, `_`, `-`. The brand family comes first in the stack, then the base family and the base tail. Only `google` families get a brand spec in `googleFonts`; other roles copy the base spec [fonts.ts:buildFontPlan].
- `buildThemeManifestJson` sets the font stacks and `googleFonts` as JSON values after rendering, so a family name cannot break `theme.json` [index.ts:buildThemeManifestJson].
- `extractBrand` passes the palette through core `ensureContrastSafe` and reports remaining failures in `stillFailing`. It throws when no color or font is found [extract-brand.ts:extractBrand].
- Local CSS is at most 20 MiB [extract-brand.ts:MAX_LOCAL_CSS_BYTES].
- Static fetch limits: 5 MiB per response, 32 stylesheet links, 20 MiB combined CSS, 5 redirects, 10 s timeout, 2 s DNS timeout. Only `http:`/`https:` [fetch-css.ts:MAX_BYTES, MAX_STYLESHEET_LINKS, MAX_COMBINED_CSS_BYTES, MAX_REDIRECTS, TIMEOUT_MS, fetchText].
- SSRF guard: private or internal hostnames and addresses are refused, before any browser launch [fetch-css.ts:assertPublicHostname, playwright-fallback.ts:extractComputedStyles]. `extractComputedStyles` skips this check for `file:`, `data:`, `blob:`, `about:` (`NON_NETWORK_SCHEMES`); through `extractBrand` those schemes fail earlier in `fetchText` (`Unsupported URL scheme`).
- In the Chromium fallback, every page request passes `guardRoute`. Any error aborts the request (fail closed) [playwright-fallback.ts:extractComputedStyles, guardRoute].
- The CLI runs only when the file is the direct entry point, so tests can import it [index.ts module guard].

## Side Effects

- Disk write: `scaffoldTheme` creates `outputDir` (default `packages/themes/<name>` under cwd) and writes `theme.json`, `package.json`, `pyproject.toml`, `README.md` [index.ts:scaffoldTheme, buildProgram].
- Disk read: templates from `getTemplateDir()`; the `--from-css` file; the `--from-pptx` file after a size check [index.ts:renderTemplate, extract-brand.ts:readLocalCssBounded, readTemplateBounded]; the base theme manifests from `@presentation-md/core/themes/*` [fonts.ts:baseTypography].
- Network: HTTP fetches of the brand page and its stylesheets, plus DNS lookups [fetch-css.ts:fetchText, assertPublicHostname].
- Process spawn (fallback only): `npm install --prefix <package root> --no-save playwright@^1.46.0` when it is missing, then `playwright install chromium` on every call, each with a 300 s timeout. Then a headless Chromium launch [playwright-fallback.ts:ensurePlaywrightInstalled, extractComputedStyles].
- stdin/stdout prompts in interactive mode; `process.exit(1)` on CLI errors [index.ts:collectView, buildProgram].
