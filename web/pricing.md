# Pricing — presentation-md

## Free (the only tier)

- **Price:** $0/month — forever free
- **License:** MIT open source
- **No account required**
- **No usage limits**

### What's included

- Full skill for all supported agents (Claude Code, Cursor, Codex, Gemini CLI, GitHub Copilot)
- MCP server with 12 typed tools: `render_deck`, `export_deck`, `audit_deck`, `judge_deck`, `list_themes`, `apply_theme`, `generate_deck_prompt`, `scaffold_deck`, `preview_themes`, `import_pptx`, `import_markdown`, `import_brand_theme`
- Node.js and Python renderers
- 75 themes (`claude` + `default-tech` bundled; 73 more as `@presentation-md/theme-*`)
- Self-contained HTML output (no hosting required)
- npm + PyPI packages

### Install

```
npx @presentation-md/install <agent>
```

Replace `<agent>` with: `claude-code`, `cursor`, `copilot`, `codex`, or `gemini-cli`
