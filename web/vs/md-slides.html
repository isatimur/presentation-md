presentation-md
vs md-slides

Markdown-first tools (md-slides, Marp, Slidev, generic presentation.md packs) win on typing speed. presentation-md wins when an agent must ship gallery-grade craft, re-theme, audit, and open PowerPoint.

Where Markdown tools are stronger

  • Lowest friction if you already think in Markdown and want git-diffable prose
  • Dev-native ecosystems (Slidev) with Vue components and live reload
  • Familiar authoring for docs-heavy teams

Where presentation-md is stronger

  • Agents produce asymmetric, theme-true decks by default — not “Markdown with a CSS skin”
  • Same JSON re-themes across 75 looks without rewriting slides
  • PPTX + Studio + MCP make it a product, not a personal CLI recipe

Verdict

Keep Marp/Slidev/md-slides when Markdown is the artifact. Use presentation-md when the artifact is a presentation — and your coding agent should hit the craft ceiling of the stunning twenty-five.
