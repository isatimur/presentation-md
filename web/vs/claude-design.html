presentation-md
vs Claude Design

Claude Design (Anthropic Labs) is a subscription canvas for slides and prototypes. presentation-md is the open, agent-native deck stack — Deck JSON, 75 themes, MCP, Studio, and PPTX you own.

Where Claude Design is stronger

  • Vision-first canvas iteration with Opus-class models inside Anthropic’s UI
  • Conversational charts and brand-system application without leaving the chat
  • One-click Canva / Claude Code handoff for teams already in that ecosystem

Where presentation-md is stronger

  • Open, portable Deck JSON — same deck survives theme swap, audit, and PPTX round-trip
  • Works in every coding agent, not only Claude’s seat — MCP-native by design
  • 75 gallery-proven themes with stunning-25 flagships (Solstice ultra-luxury, Aurora Glass, …)
  • No subscription gate to author or ship a deck you fully own

Verdict

Use Claude Design when you want a hosted visual canvas inside Anthropic’s product. Use presentation-md when the deck must live in your agent loop — schema, themes, Studio, MCP, and PPTX without a seat tax.
