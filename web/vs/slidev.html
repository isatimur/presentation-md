vs Slidev

Slidev requires you to author. presentation-md lets your agent author.

Where Slidev is stronger

  • Code-friendly (syntax highlighting, live demos)
  • Git-versionable
  • Strong dev community
  • Highly customizable Vue components

Where presentation-md is stronger

  • Agent writes the spec — you just describe what you want
  • No dev server needed — single HTML file opens anywhere
  • Works inside Claude Code, Cursor, Copilot, Codex, Gemini CLI
  • Free, MIT licensed

Verdict

Slidev is excellent for technical talks where you hand-author every slide. presentation-md is for when you want an AI agent to generate the deck from notes or a brief — less control, much less effort.
