Where frontend-slides is stronger

  • Community momentum and README gallery energy as the reference for bold agent slide aesthetics
  • Fully freeform multi-page HTML when you abandon schema on purpose (we keep custom-html + craft recipes for one-off art inside Deck JSON; Studio also Opens Marp/md-slides .md into Deck JSON)
  • Early marketplace install mindshare — we now ship /slides + plugin MCP too; their clone/copy skill flow remains familiar

Where presentation-md is stronger

  • Same show-don’t-tell discovery — site/Studio/MCP mood browse chips + Studio pick-3 My deck restyle (your slide live across themes, Generate discover parity) + filmstrip thumbs + MCP preview_themes json deck restyle (agent parity) + Craft proofs Title/Bento/Compare strips + Compare 3 (safe/bold/wildcard) + Example bridge + suggested_preview + inline PNGs + CLI --preview-compare PNG parity + Studio Copy link restores the editable deck (compressed ?d=)
  • One-shot craft bar — stunning-25-first, anti-slop, density lock, then audit_deck/judge_deck before ship (optional apply_safe_fixes)
  • Schema-validated Deck JSON — reproducible, auditable agent output across 18 layouts
  • 75 structured theme proofs with popular/mood browse on the site + Studio shortlists
  • Native PPTX export/import with speaker notes — opens in PowerPoint, Keynote, Google Slides — plus MCP/CLI vector PDF (print pipeline, not screenshots)
  • Browser Studio + 13 MCP tools (incl. judge_deck, import_markdown, export_deck format: md, share_deck_link, craft-gate audit_deck, apply_theme + default repairCraft) for agents that need a product, not only a prompt — Studio also Opens/Pastes/Downloads .md, Pastes Brand CSS, Opens PPTX, and shares live decks via Copy link
  • Claude Code /slides slash + marketplace plugin MCP — install via plugin or npx @presentation-md/install claude-code
  • Schema-safe custom-html recipes (split / big-number / stamps / type explosion) + Studio insert presets — freeform energy without abandoning Deck JSON
  • Brand import with contrast guards so muted copy stays readable
  • Density modes (speaker-led vs reading-first) in skill + Studio generate

Verdict

Use frontend-slides when you want maximum HTML freedom and slash-command gallery energy. Use presentation-md when the deck must survive re-theme, audit, PPTX handoff, and agent loops — we matched their show-don’t-tell discovery bar, then shipped the structured product layer a skill-only repo cannot.
