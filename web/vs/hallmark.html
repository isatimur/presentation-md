Hallmark is the viral anti-AI-slop page/UI skill (Together AI). presentation-md is the anti-slop deck stack — same craft refusal energy, schema + MCP + Studio share + PPTX. Honest side-by-side below.

Different jobs, same shelf

  • Hallmark (Nutlope/hallmark · usehallmark.com): design skill for greenfield pages, audits, redesigns, and DNA study from URL/screenshot. ~20 themes, 21 macrostructures, 57 slop-test gates, four verbs.
  • presentation-md: agent-native slide decks — typed Deck JSON, 75 themes, craft audit + judge, 14 MCP tools, Studio, editable PPTX.
  • You keep: anti-slop taste, skills.sh install habit, opinionated craft before emit
  • You gain (for decks): re-theme without rewrite, audit/repair loop, Office handoff, shareable editable Studio links

Prefer zero commitment? Open Studio with no install.

One-prompt → shareable artifact

Hallmark’s killer flow is brief → working HTML page. We close that gap for decks with the same shelf energy:

scaffold_deck(purpose, theme)
→ craft-floor Deck JSON
→ studio_share_url (?d= compressed token)
→ user opens editable Studio · agent continues with audit_deck / fill copy 
npx @presentation-md/install claude-code
# then ask: scaffold a pitch deck and give me the Studio link

CLI parity: presentation-md-render --scaffold pitch -o deck.json prints a Studio share URL. Studio Land scaffold + Copy link match the same codec.

Where Hallmark is stronger

  • Best-in-class anti-slop page craft — structural variety (macrostructures), nav/footer archetypes, responsive gates, study-from-URL/screenshot DNA
  • Viral gallery energy and Together AI distribution mindshare for UI generation
  • Four crisp verbs with deep reference packs for greenfield sites, audits, and redesigns inside existing codebases

Where presentation-md is stronger

  • The right product when the ask is a deck — pitch, wrap, keynote, investor update — not a landing page
  • Schema-validated Deck JSON you can re-theme, remorph, audit, and round-trip through PPTX
  • 75 published themes with structured gallery proofs + Studio pick-3 / My deck restyle
  • MCP craft loop: scaffold (with share URL) → audit/repair → judge → render/export
  • Hosted Studio with Present chrome and shareable ?d= editable links
  • Works across five coding agents with one installer — not only the Claude/Cursor/Codex skill shelf

Verdict

Use Hallmark when you need a page that refuses to look AI-generated. Use presentation-md when you need a deck that refuses the same — with schema, themes, MCP, Studio share, and PowerPoint you own. They share craft taste; they do not compete for the same artifact. No fake metrics: Hallmark leads page DNA; we lead agent-native deck shipping.
