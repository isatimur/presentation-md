How it works

Three steps from notes to deck.

Drop any raw content — bullet points, a meeting transcript, a spec doc, a README — and the skill handles the rest. It sequences your material, chooses layouts, and renders a self-contained HTML file ready to open in a browser or share as a single attachment.

Step 01

Drop your notes

Paste bullet points, a rough outline, a product brief, or anything you have. The agent reads it all and sequences it into a logical slide flow — you don't need to pre-structure anything.

Step 02

Pick a vibe

Choose from 75 themes — Claude flagship through Bauhaus, vaporwave, art deco, glassmorphism, broadsheet, and more. Same Deck JSON, completely different look. Override anytime without rewriting content.

Step 03

Get a deck

A single, self-contained HTML file lands in your project — or export native, editable PowerPoint for Keynote and Google Slides. Open HTML in any browser with no server or build step. Share either format as an attachment or drop it into Notion.

Studio

Generate, edit, present — in the browser.

The free browser Studio is a full deck workbench. No account, no upload — your deck and your API key never leave your browser.

Generate from a prompt

Describe your deck and get an editable one back. Bring your own Claude API key to generate in-browser, or copy a ready-made prompt into the agent you already use. Pick Opus 4.8, Sonnet 4.6, or Haiku 4.5.

Edit any deck, losslessly

Every rendered deck embeds its own source spec, so you can reopen a created .html and edit it with live preview. Open .pptx too — Studio maps slides into editable Deck JSON. Change layouts, swap themes, rewrite copy — autosaved to your browser.

Present & export

Present fullscreen with keyboard navigation, or export native, editable PowerPoint that opens in Keynote and imports into Google Slides — real shapes and text, not screenshots.

Themes

Seventy-five vibes. One JSON field.

Swap the entire look of a deck by changing a single "theme" key. Each theme ships a distinct surface profile — not just colors, but background treatment, decor, and motion. Full frontend-slides bold-template-pack coverage (34 systems) plus STYLE_PRESETS and gallery-craft originals. Install more with npm i @presentation-md/theme-<name>. Agents call preview_themes to render live theme previews before you commit. Layouts

Eighteen layouts. Mix and match.

Every slide picks exactly one layout. The agent chooses the right one for the content; you can always override. Each layout is a purpose-built HTML/CSS template — no DIY needed.

title

Full-bleed hero with eyebrow, headline, and a lead line. Opens any deck.

two-column

Text on the left, image or content block on the right. Great for before/after or feature + visual pairs.

feature-grid

2, 3, or 4 icon cards in a grid. Icons from FontAwesome. The go-to for listing capabilities or pillars.

quote

Large pull-quote with optional attribution. Perfect for a customer voice or a strong thesis statement.

stat-row

A row of 2–4 big-number stats with labels. Punchy metrics — revenue, users, NPS, retention.

timeline

Numbered steps on a horizontal rail. Roadmaps, onboarding sequences, historical milestones.

data-table

Structured comparison or data table with column headers. Pricing tiers, feature matrices, benchmark results.

section

A minimal divider slide: number, heading, optional lead. Use to break a long deck into chapters.

closing

Closing hero with a headline and a CTA button. Ends the deck with a clear next step or call to action.

image-hero

Full-bleed photo with a bottom scrim and short caption. Cinematic product or story beats.

comparison

Side-by-side contrast — before/after, us vs them, option A vs B. Optional emphasis grows the winning column.

code

API / SDK snippet in window chrome. Dev demos, install recipes, one-file “aha” moments — plain text, HTML-escaped.

chart

Theme-colored SVG charts — bar, line, area, pie, donut. Trends and composition without leaving Deck JSON.

ranked-list

Top-N bars with ranks and widths. Year wraps, leaderboards, and “what won” slides.

logo-wall

Customer / partner marks in a clean grid. Social proof without inventing custom HTML stickers.

streak-grid

Day-streak cells for wrap energy — filled vs total, Pulse-style craft beats.

metric-ring

Circular KPI with arc or badge ring. Percentile moments that stop the room.

custom-html

Sanitized one-off art when schema layouts aren’t enough — still round-trips in Deck JSON + Studio.

Install

One command per agent.

The @presentation-md/install CLI copies the skill files to the right place for each agent. Full mode also registers the MCP server so tools like render_deck, audit_deck, export_deck, list_themes, import_pptx, and import_brand_theme are available in-context. Copilot writes to .github/copilot-instructions.md in your project root. 

# full install — skill + MCP server (recommended)
npx @presentation-md/install claude-code

# lite — skill only, no MCP server
npx @presentation-md/install claude-code lite

# after install: restart Claude Code, then ask —
# "Build a 10-slide pitch deck from these notes: ..."
# run from the root of your project (writes .github/copilot-instructions.md)
npx @presentation-md/install copilot

# lite — skill only, no .vscode/mcp.json
npx @presentation-md/install copilot lite

# full mode also writes .vscode/mcp.json for Copilot MCP tool calls
# after install: reload VS Code window, then ask Copilot Chat —
# "Build a 10-slide pitch deck from these notes: ..."
# full install — .mdc rule + MCP server
npx @presentation-md/install cursor

# lite — .mdc rule only
npx @presentation-md/install cursor lite

# lands at: ~/.cursor/rules/presentation-generator.mdc
# full install — skill + MCP server
npx @presentation-md/install codex

# lite — skill only
npx @presentation-md/install codex lite

# lands at: ~/.codex/skills/presentation-generator/
# full install — extension + MCP server
npx @presentation-md/install gemini-cli

# lite — extension only
npx @presentation-md/install gemini-cli lite

# lands at: ~/.gemini/extensions/presentation-generator/
# render a deck JSON to HTML
npx @presentation-md/render deck.json -o deck.html
npx @presentation-md/render deck.json -o deck.html --theme corporate

# list installed themes
npx @presentation-md/render --list-themes

# validate without rendering
npx @presentation-md/render --validate deck.json

# export native, editable PowerPoint
npx @presentation-md/render deck.json --format pptx -o deck.pptx

# import PowerPoint → Deck JSON
npx @presentation-md/render --from-pptx deck.pptx -o deck.json

# or install globally
npm i -g @presentation-md/render
Full vs lite. Full mode registers the MCP server, which gives the agent eight structured tools for deterministic, re-renderable deck generation (render, export, audit, themes, PPTX import, brand import). Lite mode copies the skill definition only — the agent still works but falls back to the direct-HTML path (hand-written HTML with internal CSS). Both produce the same self-contained output file.
FAQ

Common questions.

What is presentation-md?

presentation-md is a free, open-source skill for AI coding agents. It gives Claude Code, Cursor, OpenAI Codex, Gemini CLI, and GitHub Copilot a structured, schema-validated way to generate polished slide decks. The agent fills a Deck JSON spec; a renderer turns it into a single self-contained HTML file — no design skills, no build tool, no hosting required.

How do I install it?

Run npx @presentation-md/install <agent> — replace <agent> with claude-code, cursor, copilot, codex, or gemini-cli. One command installs the skill files and optionally registers the MCP server. Restart your agent afterward and ask it to build a deck.

Is it free? Is there a paid plan?

Yes — presentation-md is completely free and MIT licensed. There is no paid plan, no account required, and no usage limits. You can use it commercially and modify it freely.

What AI agents does it support?

presentation-md supports Claude Code, Cursor, GitHub Copilot, OpenAI Codex, and Gemini CLI. It also works as a standalone CLI and exposes an MCP server compatible with any MCP-enabled agent. It is not locked to any single AI provider.

What format is the output?

Each deck is a single self-contained HTML file. It opens in any browser, requires no hosting, and no build step. You can also export to native, editable PowerPoint (`.pptx`) that opens in Keynote and imports into Google Slides, or import an existing `.pptx` back into Deck JSON. See the gallery of 75 structured theme proofs for live HTML examples.

How is this different from Gamma, Pitch, Canva, Tome, or Beautiful.ai?

frontend-slides is a discovery-first HTML prompt pack; Claude Design is Anthropic Labs' subscription canvas; Gamma, Pitch, Canva, Tome, and Beautiful.ai are web apps separate from your coding workflow. presentation-md runs inside the AI agent you already use and produces portable HTML + PPTX you own — with schema validation, 75 theme proofs, MCP tools, and Studio.
