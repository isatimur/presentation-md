# Competitor profile — frontend-slides

**Repo:** https://github.com/zarazhangrui/frontend-slides  
**Stars (approx):** ~27k (Aug 2026)  
**Artifact:** Freeform HTML presentations via coding-agent skill  
**Position vs us:** Direct rival for “agent makes slides” mindshare

## Why visitors say “this seems much better”

1. **Simpler story** — Create stunning HTML slides with your coding agent. No schema/MCP/PPTX in the first breath.
2. **Spectacular demos** — README bold-template gallery with multiple real screenshots per template.
3. **Progressive disclosure** — `SKILL.md` is a phase map; `STYLE_PRESETS.md` / bold pack / CSS load on demand.
4. **Zero schema friction** — Single HTML file, inline CSS/JS, open in browser. First win is immediate.
5. **Show-don’t-tell discovery** — Generate 3 visual style previews; user picks what they like.
6. **Community proof** — Star count + YouTube walkthrough create “obvious default” gravity.
7. **Viral templates** — 34 bold design systems from `beautiful-html-templates` feel like a craft museum.

## Their architecture (steal the feeling, not the freeform-only model)
