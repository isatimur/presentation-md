# Layout recipes — agent slide maps

Use these as **layout-count contracts**, not copy templates. Match the brief to a recipe,
then write theme-native voice. Every recipe assumes `audit_deck` after drafting.

Craft floors shared by all recipes:
- Force asymmetry early (`comparison`+`emphasis`, non-1-1 `two-column`, or bento).
- Investor / launch / brand: ≥1 real `image-hero` (composed visual, not icon grid alone).
- Closing: prefer `actions[]` with solid + outline pills and an `icon` on every pill.
- Add brief `notes` on 2–4 key slides for present mode / PPTX.

---

## Pitch Deck (12)

```
01 title         — Company name + one-line positioning
02 image-hero    — Manifesto visual: the world as it should be
03 stat-row      — The size of the problem (3 shocking numbers)
04 comparison    — Life without you vs life with you (emphasis: right)
05 two-column    — How it works + visual (ratio: 2-1)
06 feature-grid  — 3 core capabilities (icons on every card)
07 stat-row      — Single most impressive traction stat (variant:"hero" OK)
08 logo-wall     — Customers / design partners
09 data-table    — Why not the incumbents (your column last)
10 data-table    — Financials + projections
11 timeline      — GTM roadmap (4 quarters)
12 closing       — The ask + actions[] dual CTA with icons
```

## Sales Demo (10)

```
01 title         — Customer-personalised opener
02 image-hero    — Their world / product moment
03 comparison    — Status quo vs with you (emphasis: right)
04 stat-row      — Cost of the problem (their numbers)
05 timeline      — How it works (5 steps)
06 feature-grid  — 3 modules that map to their 3 pains
07 quote         — Customer who looks like them
08 data-table    — Pricing + what's included
09 timeline      — Implementation (4 milestones)
10 closing       — Next step (singular, specific, dated) — dual ask OK
```

## Keynote / Conference Talk (10)

```
01 title         — The provocative thesis (manifesto-style heading)
02 image-hero    — The tension visual
03 comparison    — Conventional wisdom vs the truth (emphasis: right)
04 section       — "Part 1: The Problem"
05 two-column    — The old way vs the new way (ratio: 2-1)
06 section       — "Part 2: The Principle"
07 feature-grid  — 3 things that change when you apply the principle
08 quote         — The authority who agrees
09 stat-row      — The one number that proves it (1–3 stats)
10 closing       — The invitation to act
```

## Investor Update (10)

```

02 image-hero    — Portfolio or thesis visual

07 timeline      — Forward guidance (4 initiatives)
08 data-table    — Risk register
```

## Product Launch (10)

```
01 title         — Product name + launch promise (not "Announcing…")
02 image-hero    — Hero product moment / cinematic still
03 comparison    — Before vs after the product (emphasis: right)
04 feature-grid  — 3 launch pillars (icons required)
05 stat-row      — Proof metrics (waitlist, beta NPS, latency)
06 quote         — Design partner or early user
07 timeline      — Launch week beats
08 logo-wall     — Press / partners / stack marks
09 two-column    — Pricing or access + visual (ratio: 2-1)

```

## Year Wrap / Kinetic Wrapped (8–10)

Theme: `kinetic-wrapped`. Set `tone` on ≥3 slides. Prefer wrap layouts over soft cards.

```
01 title         — Year / persona + manifesto (tone set)
02 stat-row      — Mega number (variant:"hero", tone)
03 ranked-list   — Top-N moments / tracks / commits
04 streak-grid   — Day streak / consistency proof
05 metric-ring   — Percentile / completion KPI (pct 1–100)
06 image-hero OR custom-html — Signature visual beat
07 quote OR comparison — The line that stuck / before-after
08 closing       — Share dual ask (solid + outline) with brand icons
```

## Neon / Atmosphere short (8)

Themes: `neon-noir`, `vaporwave`, `y2k-aero`. Prefer cinematic beats over SaaS grids.

```
01 title         — Mood-forward positioning
02 image-hero    — Cinematic atmosphere still
03 quote         — One sharp line
04 comparison    — Old night vs new night (emphasis: right)
05 feature-grid  — 3 capabilities (icons) — keep sparse
06 stat-row      — 1–3 proof numbers
07 two-column    — Product moment + copy (ratio: 2-1)
08 closing       — Dual ask with icons
```

## Poster / activist short (8)

Themes: `coral`, `peoples-platform`, `bold-signal`, `broadside`. Big type, hard frames — not soft SaaS cards.

```
01 title         — Poster manifesto (short, loud)
02 image-hero    — Single iconic visual
03 comparison    — Us vs them / now vs next (emphasis)
04 stat-row      — 1–3 numbers that punch
05 quote         — Rally line
06 feature-grid  — 3 demands / pillars (icons)
07 timeline OR logo-wall — Movement beats / allies
08 closing       — Dual ask (join + share)
```

## Paper / editorial short (8)

Themes: paper honesty set (`soft-editorial`, `ft-editorial`, `pink-script`, `long-table`, …). Magazine cadence.

```
01 title         — Literary cover lead
02 quote         — Opening epigraph
03 comparison    — Thesis vs foil (emphasis)
04 image-hero    — Editorial photograph / composed still
05 two-column    — Essay beat (ratio: 2-1)
06 feature-grid OR data-table — Sparse evidence
07 stat-row      — One quiet proof number
08 closing       — Dual ask (read more / subscribe)
```
