# skills

## Overview
The two agent skills in this pack. `presentation-generator` turns notes into
a Deck JSON or HTML deck and can export or deploy it. `deck-design-judge`
scores a finished deck. The adapters install both into each host.

## Subdirectories & Boundaries
- deck-design-judge: [EGM.md](./deck-design-judge/EGM.md) ([SKILL.md](./deck-design-judge/SKILL.md)) - deterministic metrics, multi-model rubric panel, and scorecard with a ready verdict.
- presentation-generator: [EGM.md](./presentation-generator/EGM.md) ([SKILL.md](./presentation-generator/SKILL.md)) - mirror of `packages/core` skill files, schemas, references, and PDF/deploy scripts.
