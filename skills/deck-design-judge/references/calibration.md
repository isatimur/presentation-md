# Calibration — what “best practices” means

The rubric is distilled from three sources:

1. **presentation-generator** — 7 Laws, Deadly Sins, type scale, 60-30-10, motion, arcs.
2. **Claude Design / Untitled-UI** (and Swiirl) — **flat** depth, Inter, purple-as-highlight (not button fill), spacing grid.
3. **WCAG AA** — contrast **gate**.

Deadly Sins map to **gates**; Laws + craft map to **scored dimensions**.

When a brand bundle ships exemplars (pitch SVGs, specimen HTML), use them as positive
anchors for “what good looks like” for that brand.
